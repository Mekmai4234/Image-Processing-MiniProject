งาน 05_dataset_testing: Dataset และการทดสอบ
เจ้าของงาน: คนที่ 5 (รอกรอกชื่อจริงใน docs/team.md)
ความยาก: ปานกลางถึงยาก (4/5)
Branch เริ่มต้น: feature/05-dataset-testing
สถานะ: แผนพัฒนา; ดู implementation-status ก่อนรันคำสั่งแอป

ENV — การเตรียมเครื่องและข้อตกลง

เป้าหมาย
เตรียมข้อมูลอ้างอิงและ ground truth สำหรับขวดไทย 2 ยี่ห้อ รุ่น/ขนาดคงที่
ทำชุดทดสอบที่ใช้ประเมินภาพจริง ไม่ใช้แต่ภาพการ์ตูนหรือแก้ภาพสังเคราะห์

อุปกรณ์และโปรแกรม
- ขวดจริงหลายใบของสินค้าเดียวกัน Webcam notebook พื้นหลังเรียบ แสงกระจาย
- Python รุ่นเดียวกับ Backend, Git, CSV editor หรือ spreadsheet
- pytest, httpx สำหรับ API tests; browser สำหรับ UI test
- เก็บภาพส่วนบุคคล/ฉากหลังที่ติดคนออกจากข้อมูลก่อนอนุญาตเผยแพร่

โฟลเดอร์ข้อมูลบนเครื่อง
datasets/references/<product_id>/        templates ที่ผ่านตรวจแล้ว
datasets/raw/<capture_session>/         original หลายมุม
datasets/manifests/                     CSV กำกับทุกภาพ
datasets/splits/                        development/validation/test manifests
datasets/config/products.json           catalog และ tolerance ที่ตกลง
ทุก path นี้ถูก ignore; แชร์ชุดข้อมูลผ่านช่องทางที่ทีมตกลงและบันทึกเวอร์ชัน
examples/ ใน repo เก็บตัวอย่างสังเคราะห์กับ header ไม่ใช่ภาพหรือข้อมูลจริง

Fields ที่ต้องเก็บ
image_id, filename, physical_bottle_id, capture_session, product_id,
expected_product, angle_deg, label_present, position_ok, visible_enough,
result, reason, split และ reviewer
มุมไม่ทราบใช้ว่าง ไม่แต่งค่า; ภาพเดียวอาจมี expected product ต่างกันได้
แต่ภาพเดียวกันต้องไม่ไปอยู่คนละ split

จำนวนเริ่มต้น
เป้าหมายทดลองประมาณ 200 ภาพ ไม่ใช่ข้ออ้างว่าพอสำหรับทุกสภาพ
กระจายทั้งยี่ห้อ สภาพแสง ขวดหลายใบ และ session ต่างกัน
ทำกลุ่ม PASS, missing label, misplaced label, wrong product และ REVIEW แยกกัน
ภาพแก้ด้วยคอมพิวเตอร์ต้องทำเครื่องหมาย synthetic และรายงานแยกจากภาพจริง

การแบ่งชุด
เป้าหมาย 60/20/20 โดยจับกลุ่ม physical_bottle_id + capture_session
ภาพหลายมุม/ภาพต้นฉบับและ augmentation อยู่ split เดียวกันทั้งหมด
ถ้าข้อมูลกลุ่มน้อยให้รายงานข้อจำกัด แทนฝืนให้ตัวเลขตรงเปอร์เซ็นต์

พร้อมเริ่มเมื่อ
ตกลงยี่ห้อ/รุ่นจริงและกฎตำแหน่งกับทีม มี manifest ตัวอย่างใน examples/labels.csv
