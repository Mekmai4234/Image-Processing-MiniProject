## เริ่มใช้งาน

เปิด `start.cmd` หรือ `powershell -File scripts/start.ps1` จาก root ต้องมี Python 3.11+ และ Node 22.12+ พร้อม npm

ถ้ามี Python/npm CLI อยู่ตำแหน่งอื่น ใช้ `-Python <python.exe> -NpmCli <npm-cli.js>` หรือกำหนดใน `.tools/runtime.json` ที่ ignore ไว้ ห้าม commit path เฉพาะเครื่อง

1. ไป `http://127.0.0.1:8000/settings`
2. เลือก Bottle A ตั้งชื่อสินค้า อัปโหลดขวดตั้งตรงเต็มใบบนพื้นหลังเรียบ
3. ปรับกรอบฟ้าให้ครอบเฉพาะฉลาก แล้วบันทึก เริ่มตรวจ Bottle A ได้ทันที; เพิ่ม Bottle B เมื่อต้องการเทียบสองสินค้า
4. Simulation: อัปโหลดภาพ เลือกสินค้า Run; หลายมุมต้องระบุมุมและยืนยันขวดเดียวกัน
5. Webcam: เปิดกล้อง หมุนขวดด้วยมือ ถือนิ่งแล้ว Capture/Auto capture หรือเลือก File ทดสอบภาพนิ่ง
6. History: ค้นหา/กรอง/เรียงลำดับ ดูหลักฐาน ดาวน์โหลด JSON/ZIP/CSV และบันทึก human review แยกจากผลเดิม

Backend ให้บริการ production build และ API ผ่าน port เดียว ภาพและฐานข้อมูลอยู่ในเครื่องที่รัน Backend ไม่ส่งเข้า GitHub

## ขอบเขตการตัดสิน

REFERENCE MODE ใช้ reference ของผู้ใช้และเกณฑ์เริ่มต้น: PASS/FAIL มีความหมายตามเกณฑ์นั้น แต่ `validated=false` เสมอ ไม่สร้างรายงาน validation สมมุติ ไม่ถือว่าภาพอ้างอิงคือชุดทดสอบอิสระ

match_score เป็น similarity ไม่ใช่ calibrated confidence หรือ accuracy ขวดโปร่งใส พื้นหลังซับซ้อน แสงสะท้อน หรือฉลากที่คล้ายกันอาจเป็น REVIEW/อ่านไม่พบ ต้องทดลองกับสินค้าจริงก่อนใช้ตรวจคุณภาพจริง

ภาพเดียวไม่ยืนยัน missing label รอบขวด; REVIEW ไม่ปล่อยผ่าน ไม่มีการหมุนมอเตอร์จริงใน webcam ผู้ใช้หมุนเอง

## หลักฐานทดสอบรุ่นนี้

- Backend: 163 tests + 94 subtests ผ่าน รวม enrollment/restart/non-DEMO PASS–FAIL–REVIEW/บันทึกไฟล์
- Frontend: 141 tests, TypeScript และ production build ผ่าน
- Dataset tools: 47 tests ผ่าน; repository validator ผ่าน
- Browser production build จาก FastAPI: บันทึก A/B ผ่านฟอร์ม → upload → silhouette ready → Simulation COMPLETE/PASS และ History
- Browser File mode: ภาพฉลาก B เมื่อเลือก A ได้ FAIL/wrong_label พร้อมกรอบแดง; History ค้นหา/กรองและดาวน์โหลด CSV/ZIP (original, annotated, result.json) ได้จริง
- เมื่อไฟล์ annotated ใน temporary storage หาย หน้า History แสดง missing และซ่อน ZIP; ทวน responsive History/Webcam ที่ 390px ไม่มี horizontal overflow
- ใช้ข้อมูลสังเคราะห์/temporary storage แยกจากข้อมูลจริง ไม่ใช่ผล accuracy ของขวดไทยหรือ hardware acceptance
- Webcam กับขวดจริงและ validation dataset อิสระยังต้องทวนโดยทีม ไม่แก้ checklist เก่าเป็น passed โดยไม่มีหลักฐาน
