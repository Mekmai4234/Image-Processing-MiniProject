เป้าหมาย
ทำตัวตรวจฉลากจริงที่ใช้ร่วมกันใน upload/simulation และ webcam
เริ่มสินค้ารหัส bottle_a/bottle_b จนทีมยืนยันยี่ห้อ รุ่น และขนาดจริง

สิ่งที่ใช้
- Python 3.11 หรือ 3.12 (ตกลงรุ่นเดียวกันในทีม), venv, Git
- opencv-python-headless, numpy, Pillow สำหรับประมวลผลและวาดผล
- pytest สำหรับ unit/integration tests; dataset กับคำตอบจากคนที่ 5
- ไม่ต้องมี LLM/API key หรือ GPU สำหรับ baseline แบบ classical image processing

เตรียม Python ที่ root repository (PowerShell)
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r apps/backend/requirements.txt
ถ้ามีเฉพาะ Python 3.12 ใช้ py -3.12 และบันทึกรุ่นร่วมกับคนที่ 4
เรียก python.exe ใน venv โดยตรงได้ ไม่จำเป็นต้องเปลี่ยน ExecutionPolicy

ชุดข้อมูลจริงยังไม่ถูกเตรียมใน scaffold และไม่ commit ลง public repository

ค่าที่ต้องตกลง
- ความหมาย match_score และวิธี matching เดียวที่รองรับใน baseline
- เกณฑ์ภาพเบลอ ขนาดฉลากต่ำสุด และส่วนต่างคะแนนระหว่างอันดับหนึ่ง/สอง
- tolerance ตำแหน่งและมุม เลือกจาก requirement และ validation set
- ค่าเกณฑ์ในเอกสารเป็นตัวอย่าง ห้ามนำไปอ้างเป็นเกณฑ์ที่ validate แล้ว

พร้อมเริ่มเมื่อ
นำเข้าชุดภาพอ้างอิงที่ได้รับอนุญาต อ่าน API contract และได้รับ ground truth ชุดแรก
