งาน 04_webcam_backend_logging: Webcam, API และบันทึกลงเครื่อง
เจ้าของงาน: คนที่ 4 (รอกรอกชื่อจริงใน docs/team.md)
ความยาก: ยาก (4/5)
Branch เริ่มต้น: feature/04-webcam-backend
สถานะ: แผนพัฒนา; ดู implementation-status ก่อนรันคำสั่งแอป

ENV — การเตรียมเครื่องและข้อตกลง

เป้าหมาย
เชื่อม browser webcam / upload กับตัวตรวจของคนที่ 3 และเขียนภาพ/Log ลงเครื่อง
ตัวโค้ด Webcam อยู่ frontend; API และการเขียนไฟล์อยู่ Backend

เครื่องมือ
- Git, Python 3.11/3.12 ตามทีม, venv และ requirements.txt ใน apps/backend/
- FastAPI, Uvicorn, python-multipart, Pillow, OpenCV และ SQLite ใน Python stdlib
- Node/npm รุ่นเดียวกับคนที่ 1 สำหรับ camera feature
- Webcam notebook และสิทธิ์กล้องของ browser

ติดตั้ง (PowerShell ที่ root)
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r apps/backend/requirements.txt
if (-not (Test-Path .env)) { Copy-Item .env.example .env }
ไฟล์ .env และภาพจริงจะไม่ถูก track โดย git
requirements เป็นรายการเริ่มต้น ยังไม่ใช่ lock ที่ยืนยันจากการทดสอบทั้งระบบ

ตำแหน่งโค้ด
apps/web/src/features/webcam/       CameraPanel, frame capture, cleanup
apps/backend/app/main.py           app/CORS/config
apps/backend/app/api/              health, products, locate, inspections, history
apps/backend/app/services/         jobs, results, file storage
apps/backend/app/db/               SQLite schema และ migration
apps/backend/tests/api/ และ tests/storage/

ค่าตั้ง
WEB_ORIGIN=http://localhost:5173 ต้องตรงกับ frontend จริง
VITE_API_BASE_URL=http://127.0.0.1:8000 เป็น URL สำหรับเบราว์เซอร์
STORAGE_ROOT=./storage และ DATASET_ROOT resolve เทียบ repository root เสมอ ไม่ใช่ cwd
อ่าน .env ที่ root แบบ explicit; รายละเอียดอยู่ docs/configuration.md
DATASET_ROOT=./datasets; APP_TIMEZONE=Asia/Bangkok; MAX_UPLOAD_MB=10
เก็บ timestamp UTC ใน record แล้วแสดงเวลาไทยบน UI

กล้อง
browser ใช้ getUserMedia หลังผู้ใช้กดเปิด/ให้สิทธิ์; localhost หรือ HTTPS
หากเลือก camera/device ให้ตรวจอุปกรณ์ที่มีจริง; ปิด tracks เมื่อออกหน้า/ปิดกล้อง
ไม่ต้องซื้อแท่นหมุน: Webcam mode ผู้ใช้หมุนขวดด้วยมือ

ที่เก็บข้อมูล
Backend ต้องรันเครื่องเดียวกับที่ต้องการเก็บภาพอัตโนมัติ
ถ้ารันบน hosting ภาพจะอยู่ที่ hosting ไม่ได้เขียน D: ของผู้ใช้โดยตรง
ใช้ path ที่กำหนดโดยโปรแกรม ไม่รับ absolute path อิสระจาก client

สถานะ scaffold
ยังไม่มี app/main.py หรือ API ที่รันได้; คำสั่ง uvicorn จะใช้ได้หลังสร้าง app แล้ว
ส่งคำสั่งรันที่ทดสอบจริงใน apps/backend/README.md เมื่อจบ PR แรก
