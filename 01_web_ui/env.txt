เป้าหมาย
เตรียมเครื่องสำหรับเว็บ React + TypeScript มี 3 หน้าชัดเจน ได้แก่ Simulation,
Webcam และ History; ใช้เว็บเดียวร่วมกับงาน 02 และ 04

สิ่งที่ติดตั้ง
- Git, Node.js 22.12+ ภายในสาย 22 และ npm; ทีมต้องตกลงรุ่นเดียวกันก่อนสร้าง lockfile
- เบราว์เซอร์ที่รองรับ getUserMedia; ใช้ Chrome/Edge ที่เครื่องทีมมี
- Editor ที่แก้ UTF-8 ได้ เพื่อให้ข้อความภาษาไทยไม่เสีย
- เมื่อเริ่ม implementation: Vite, React, TypeScript, CSS; คนที่ 2 เพิ่ม Three.js
- ยังไม่บังคับชุด UI library เลือกแล้วบันทึกใน PR แรกเพื่อไม่ใช้ซ้อนกันหลายชุด

ค่าตั้งระบบ
VITE_API_BASE_URL เป็น URL หลังบ้าน เช่น http://127.0.0.1:8000
ตัวแปร VITE_* ถูกส่งไปเบราว์เซอร์ ใช้เฉพาะข้อมูลสาธารณะที่หน้าเว็บต้องรู้
WEB_ORIGIN ฝั่ง Backend ต้องตรงกับ origin ที่เปิดเว็บจริง

ข้อตกลงร่วม
- เก็บ package.json และ package-lock.json ใน apps/web/; ทุกคนใช้ npm ci หลังมี lockfile
- คนที่ 1 เป็นเจ้าของ app shell; คนที่ 2/4 ส่ง features ของตัวเองเข้ามาผ่าน PR
- ขนาด bbox อ้างอิงภาพต้นฉบับ ไม่ใช่ CSS pixel ของจอ
- ใช้ mock จาก examples/ ก่อน API จริงพร้อม แล้วมีป้าย DEMO ชัดเจน

สิ่งที่ยังไม่มีใน scaffold นี้
ยังไม่มี package.json หรือ React app; ยังรัน npm ci / npm run dev ไม่ได้
งานแรกคือสร้าง app shell ใน apps/web/ โดยรักษา README เดิมและ commit lockfile
จากนั้นกำหนด npm run dev, npm run build และคำสั่งทดสอบใน README ของเว็บ

พร้อมเริ่มเมื่อ
เปิดต้นแบบ HTML ได้, อ่าน docs/api-contract.md แล้ว และรู้ path ที่ตนแก้

อ่าน docs/configuration.md: Vite ใน apps/web ต้องตั้ง envDir ให้ชี้ repository root
คง envPrefix เป็น VITE_ และห้ามส่ง process.env ทั้งก้อนเข้า browser
