สถานะ: M3 — component + ตัวต่อ DataSource (#23), ฉากเครื่องจักรแยก ORIENT/INSPECT (#25), รูปทรงขวดจาก bottle-silhouette-v1 (#27) เข้า develop แล้ว; ฉากแบบสมจริง (#31) เข้า develop แล้ว; ทดสอบกับ DEMO และภาพทดสอบเท่านั้น ยังไม่ต่อ backend จริง; ดู apps/web/src/features/simulation/README.md

ENV — การเตรียมเครื่องและข้อตกลง

เป้าหมาย
ฉากจำลองสายพาน 3D จริงบนเว็บร่วมกับ app shell ของคนที่ 1
ต้นแบบ SVG เดิมใช้ดู flow เท่านั้น ต้องแยกจากผลงาน Three.js ที่จะพัฒนา

สิ่งที่ใช้
- Git, Node.js/npm รุ่นเดียวกับคนที่ 1 และ browser ที่รองรับ WebGL
- React + TypeScript ใน apps/web/ ที่คนที่ 1 ตั้งไว้
- Three.js สำหรับ scene, camera, lighting และ model; เลือก integration แบบเดียวทั้งทีม
- เริ่มจาก geometry พื้นฐานได้ ไม่ต้องซื้อโมเดล; assets ภายนอกต้องมี license/source

ตำแหน่งโค้ดที่รับผิดชอบ
apps/web/src/features/simulation/
apps/web/public/models/           เฉพาะโมเดลที่เผยแพร่ได้
apps/web/src/types/inspection.ts  ใช้ type ร่วม ห้ามแยกชื่อ field เอง

Input ที่ต้องมี
- product_id และภาพ/ชุดภาพหลายมุมของขวดเดียว
- angle_deg ของแต่ละภาพ; เริ่ม 0,30,...,330 องศา แล้วปรับตามเวลาโปรเจกต์ได้
- InspectionResult จริงหรือ mock ที่ติดป้าย DEMO เพื่อพัฒนาฉาก

ค่าตั้งเริ่มต้น
ROTATION_STEP_DEG=30, MAX_ROTATION_DEG=360, จำกัดทั้งจำนวนมุมและเวลา
ความเร็วสายพาน/เวลารอภาพนิ่งเป็น config จำลอง ไม่ใช่การวัดอุปกรณ์จริง
ลด motion ตามระบบผู้ใช้และมี pause; วัดเฟรมเรตบน notebook ของทีม

ข้อจำกัดที่ต้องอธิบายบน UI
ภาพเดียวเห็นเฉพาะด้านที่ถ่าย ไม่สามารถหมุนให้เกิดฉลากด้านหลังจริงได้
โหมดภาพเดียวจึงข้ามการค้นหารอบขวดหรือแจ้งให้เพิ่มภาพหลายมุม
การตัดพื้นหลังให้เหมือนรูปเป็นการแสดงผล ไม่ใช่หลักฐานตัดสิน PASS/FAIL

พร้อมเริ่มเมื่อ
คนที่ 1 มี app shell หรือทำ scene แยกด้วย mock contract เดียวกัน
อ่าน docs/architecture.md และ docs/api-contract.md แล้ว

ค่าหมุนใช้ผ่าน GET /api/products ใน simulation_defaults ที่ Backend ตรวจแล้ว
ไม่อ่าน .env ฝั่งเครื่องผ่าน browser โดยตรง; contract และ docs/configuration.md กำหนด field ร่วม

การรันและทดสอบ (M3)
cd apps/web แล้ว npm install, npm test, npm run build (ใช้คำสั่งเดียวกับทั้งเว็บของ 01)
unit test ของ 02 อยู่ใน apps/web/src/features/simulation/__tests__/
three อยู่ใน apps/web/package.json แล้ว (plain Three.js + React wrapper ไม่ใช้ React Three Fiber)
ฉากไม่โหลด asset ภายนอก: วัสดุ/ลาย/ฉลากวาดในโค้ด ไม่มีปัญหา license
ดูฉากได้ที่หน้า Simulation ของ 01 โหมด DEMO → ใช้ชุดภาพตัวอย่าง → Run

ภาพขวดที่ใช้ทดสอบฉาก (ภาพ AI ของ 05, ภาพจากชุดข้อมูลงานวิจัย) ใช้ในเครื่องเท่านั้น ไม่เข้า Git
